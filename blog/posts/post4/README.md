# Blog 4: Home Prices, Mortgage Rates, and Monthly Payments

This post examines how changes in U.S. home prices and mortgage rates affected the monthly cost of financing a home between January 2019 and December 2024. I use three visualizations to compare home prices, borrowing costs, and estimated mortgage payments.

## Data

The analysis uses three series downloaded from [FRED](https://fred.stlouisfed.org/):

- [CSUSHPINSA](https://fred.stlouisfed.org/series/CSUSHPINSA): S&P Cotality Case-Shiller U.S. National Home Price Index, from S&P Dow Jones Indices.
- [MORTGAGE30US](https://fred.stlouisfed.org/series/MORTGAGE30US): 30-Year Fixed Rate Mortgage Average in the United States, from Freddie Mac.
- [CPIAUCSL](https://fred.stlouisfed.org/series/CPIAUCSL): Consumer Price Index for All Urban Consumers: All Items, from the U.S. Bureau of Labor Statistics.

The data were downloaded programmatically on October 6, 2026. The original CSV files are included in `data/raw/` so the analysis can be reproduced using the same data. The R script downloads a series from FRED if its local file is missing. No API key is required.

## Reproduce the Analysis

Install the required R packages once:

```r
install.packages(c("tidyverse", "lubridate", "scales"))
```

Set the working directory to this folder, which contains `index.qmd` and this README. Then run:

```r
source("code/analyze.R")
```

This saves the processed data, summary values, and figures. To generate the blog page, open `index.qmd` in RStudio and click **Render**, or run:

```bash
quarto render index.qmd
```

Rendering also runs the analysis script. The post has been successfully rendered in RStudio. Within my website, these files belong in `blog/posts/post4/`.

## Calculations and Assumptions

I average the weekly mortgage rates within each month and combine them with the monthly home price index and CPI. The analysis contains 72 months, from January 2019 to December 2024, with no missing values after combining the series.

Both nominal and inflation-adjusted home prices are expressed relative to January 2019 = 100. Inflation-adjusted prices divide the home price index by CPI, with both series normalized to the same starting month.

For the payment calculation, I assume a home worth $300,000 in January 2019, a 20% down payment, and a 30-year fixed mortgage. The hypothetical home value changes with the national home price index. Each month represents a new loan at that month's average mortgage rate. A second calculation holds the rate at its January 2019 value to compare the payment paths.

For loan principal `L` and monthly interest rate `r`, the monthly payment is:

```text
L * r / (1 - (1 + r)^(-360))
```

The monthly interest rate is the annual percentage rate divided by 100 and then by 12. Inflation-adjusted payments are expressed in January 2019 dollars.

These payments include principal and interest only. They exclude taxes, insurance, maintenance, and closing costs. The $300,000 starting price is illustrative, rather than a national median. The analysis does not measure household income or changes in payments for existing fixed-rate borrowers.

The home price series is not seasonally adjusted, while CPI is seasonally adjusted, so I focus on changes over several years. Freddie Mac changed its mortgage-rate survey methodology in November 2022. The fixed-rate comparison illustrates the payment calculation; it does not estimate what home prices would have been under different interest rates.
